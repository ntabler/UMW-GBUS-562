# UMW-GBUS-562
Repository for GBUS 562 (AI Language Models)

## About
This repository holds materials created for GBUS 562 (AI Language Models) at the University of Mary Washington (UMW). Content is organized into weekly folders, so each week's assignments, notes, and code are grouped together.
